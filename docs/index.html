Need to set up or change Wi-Fi?

Wi-Fi details are entered on the ESP32's local setup page, not sent through this website.

  1. Find the ESP32-Relay-Setup- network in your phone’s Wi-Fi list and connect using the setup password you configured for the ESP32.
  2. If asked, stay connected even though this setup network has no internet.
  3. Open the local setup page, scan for your home 2.4 GHz network, and save its password.
Open ESP32 setup page

The link works only while your phone is connected directly to the ESP32 setup Wi-Fi. You do not need PlatformIO to enter your home Wi-Fi details.

i Schedules repeat daily in Asia/Kolkata time. If the ESP32 misses polling for more than 15 seconds across a scheduled start, that day's run is skipped.
