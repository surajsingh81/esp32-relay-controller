Help & device information

Setup steps, schedule details, and live controller activity.

Set up Wi-Fi

  1. Connect your phone to the controller's ESP32-Relay-Setup- hotspot using your setup password.
  2. Stay connected if your phone warns that the hotspot has no internet.
  3. Open the setup page, select your 2.4 GHz home network, enter its password, and save.
Open ESP32 setup

Your phone must be connected directly to the controller hotspot for this link to work. Wi-Fi credentials are saved on the controller and are not sent to the cloud.

Automatic schedules

  • Each device output can have up to 20 daily start times and durations.
  • All times use Asia/Kolkata time and repeat daily.
  • The device stays ON while any saved timing is active; overlapping timings do not switch it OFF between windows.
  • If the controller misses a timing's start while offline for more than 15 seconds, that window is skipped for the day.

Connection and device status

The dashboard shows the requested output state, not independent electrical feedback. The controller applies changes on its next check-in.

The device connects outbound to the control service over HTTPS. Router port forwarding is not required.

Manual and Auto modes

  • Manual: use the ON/OFF buttons to request a device state.
  • Auto: add timings and save them. The device follows the saved daily windows.
  • Switch back to Manual whenever you want to control the device with buttons.
